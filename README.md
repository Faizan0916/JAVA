## 🚀 Getting Started

### Prerequisites

- [JDK 17+](https://adoptium.net/) (check with `java -version`)
- A C++ compiler such as `g++` (only for `oops.cpp`)
- Python 3 (only for `ml.py`)

### Clone

```bash
git clone https://github.com/Faizan0916/JAVA.git
cd JAVA
```

### Run a Java program

```bash
javac loops.java
java loops
```

> The class name must match what is inside the file. If a file has a `public class` with a different name, run that class name instead.
